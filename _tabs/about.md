Ce blogue documente [PocketBase](https://pocketbase.io/), un serveur d'application livré en un seul fichier exécutable, dans le cadre d'un projet de prêt d'équipement de laboratoire.

Il fait partie d'un ensemble de trois livrables :

- le [dépôt du projet](https://github.com/202430022/5sh-tp4), avec le README et le code des migrations ;
- le [wiki](https://github.com/202430022/5sh-tp4/wiki), avec les procédures, les références et le dépannage ;
- ce blogue, avec le récit, l'analyse et l'avis.

Les articles sont écrits à la première personne et s'appuient sur des manipulations réelles : les messages d'erreur cités ont été obtenus sur un poste Windows avec PocketBase 0.40.6, et les réponses de l'API proviennent de requêtes exécutées avec deux comptes de rôles différents.

Le code du site utilise le thème [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy), publié sous licence MIT.
